문제

토큰 재생 방식이 막히는 이유

당근 앱은 토큰 하나로 인증하지 않는다. 요청마다 아래를 함께 검사 — 하나만 빠져도 차단.

기기 바인딩토큰이 로그인한 기기에 묶임 — 다른 환경이면 불일치
무결성 검사Play Integrity — 에뮬레이터(LD플레이어)는 통과 불가
요청 서명앱 런타임이 생성하는 서명 헤더 — 스크립트엔 없음

→ “토큰 추출 → HTTP 재생”은 세팅 문제가 아니라 방식의 한계. 우회보다 경로 전환이 정답.
